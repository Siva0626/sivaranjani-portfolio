# Content Requirements

## Personal
- Professional name
- Professional title
- Short introduction
- Bio
- Profile image if required

## Work / Projects
For each item collect:
- Name
- Context
- Objective
- Role
- Responsibilities
- Work performed
- Tools
- Outcome/result
- Link
- Screenshots/images if available

## Course creation
- Course name/topic
- Role
- Structure/content created
- Tools
- Output

## Data analysis
- Project
- Data source/type
- Analysis performed
- Tools
- Insight/output

## Contact
- Professional email
- Professional social links
- Other relevant contact methods

## Content rule
If information is missing, use a clearly marked placeholder and ask for the real information. Do not invent it.
