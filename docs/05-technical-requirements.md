# Technical Requirements

## Initial architecture
Start with a responsive frontend. Backend/database/API are optional and should be introduced only when requirements need them.

## Planned technologies
- AI coding: Codex
- Editor/IDE: VS Code
- Version control: Git
- Repository: GitHub
- Database: Supabase, if needed
- Deployment/hosting: Render
- DNS/CDN/security: Cloudflare later if needed
- API testing: Postman if APIs are introduced

## Frontend
Responsive, accessible, reusable components, clear interaction states, mobile/tablet/desktop support.

## Security
Never expose secrets/API keys in frontend. Use environment variables. Validate user input. Use HTTPS in production.

## Deployment
Initial deployment can use Render's provided URL. Custom domain is not required for MVP.
